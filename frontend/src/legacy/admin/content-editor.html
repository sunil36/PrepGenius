What is MRO in Python?

In Python, Method Resolution Order (MRO) defines the exact sequence in which base classes are searched when looking for an attribute or method on an instance. Since Python 2.3, the C3 Linearization Algorithm is used to resolve ambiguous multiple inheritance diamond problems.

Rule of C3: A class always precedes its parents, and the original order of base classes is strictly preserved without cyclic dependencies.

Key Senior Interview Pitfalls

Candidates often assume super() simply calls the immediate parent class. In multiple inheritance, super() delegates to the next class in the MRO graph, not necessarily the parent!
