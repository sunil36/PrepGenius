# PrepPilot API

PrepPilot backend service built with FastAPI and MySQL.

## Structure

- `app/`: Application source code (api, core, db, modules, infrastructure, integrations, workers)
- `tests/`: Test suites (unit, integration, api, security, performance)
- `alembic/`: Database migrations
- `docker/`: Docker configurations
- `docs/`: Architecture documentation and runbooks
- `scripts/`: Automation scripts
